# Hexo + NexT 博客

使用 Hexo 框架和 NexT 主题搭建个人博客

[https://hexo.io/zh-cn/](https://hexo.io/zh-cn/)  
[https://theme-next.js.org/](https://theme-next.js.org/)

使用 node 版本为 v20.20.0 安装依赖

```shell
pnpm install
```

清理静态目录

```shell
hexo cl
```

生成静态目录资源

```shell
hexo g
```

启动服务

```shell
hexo s
```

推送到 Github 仓库

```shell
hexo d
```
